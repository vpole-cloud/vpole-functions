# Contributing to the vPole Functions SDK

Thank you for your interest in improving the vPole Functions SDK.

No contributor license agreement is required for this repository. The vPole control plane
([vpole-cloud/vpole](https://github.com/vpole-cloud/vpole)) is licensed separately and requires
one.

## Workflow

- Fork the repository (or use a branch if you have write access) and open a pull request against
  `main`.
- Keep pull requests focused, with concise conventional-style commit subjects.
- Build and run the tests before requesting review.
- Never commit secrets.

## Reporting security issues

Do not report vulnerabilities in public issues. Use the repository's **Security** tab and select
**Report a vulnerability**.
